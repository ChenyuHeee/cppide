340	## 5. AI 子系统
341	
342	### 5.1 线程模型
343	
344	- **一个** worker 线程,仅在 `cfg.aiEnabled()` 时创建。它阻塞在 `in_.waitPop(req, 200ms)` 上。
345	- UI 线程与 worker 之间只有两个 `Mailbox`:请求进、事件出。UI 线程**只用 `tryPop`**,永不阻塞。
346	- 主循环用 `timeout(60)` 让 `getch()` 在空闲时每 60ms 返回 `ERR`,以此驱动 500ms 停顿判定。**不用 `halfdelay()`** ——它只有 100ms(十分之一秒)粒度且强制 cbreak 语义。60ms 唤醒的空闲 CPU 接近 0,因为 ncurses 底层就是在 tty 上 poll。
347	
348	```cpp
349	enum class AiMode { Practice, Code };          // 练习模式 / 写代码模式
350	enum class AiSink { PanelOnly, GhostText };    // 回复"允许变成什么"

352	struct AiRequest {

354	  AiMode   mode;
355	  AiSink   sink;

358	};
359	
360	class AiService {
361	public:
362	  AiService(const Config& cfg, Mailbox<AppEvent>* out);
363	  ~AiService();                               // 取消 + join
364	
365	  bool   enabled() const;
366	  AiMode mode() const;  void setMode(AiMode m);  AiMode toggleMode();
367	
368	  void noteActivity();                        // 任意改动/移动光标时调用:记时间 + gen_++
369	  void maybeAutoTrigger(const TextBuffer& b, Pos cur);   // 每 tick 调用一次
370	  void askNow(const TextBuffer& b, Pos cur, const std::string& question);
371	  void cancelInFlight();
372	  uint64_t generation() const;
373	  bool inFlight() const;
374	  const char* stateZh() const;                // "就绪"/"思考中…"/"未配置"/"错误"
375	
376	private:
377	  static AiSink sinkFor(AiMode m) {           // ★ 全工程唯一的 sink 决策点
378	    return m == AiMode::Code ? AiSink::GhostText : AiSink::PanelOnly;
379	  }
380	  AiRequest buildRequest(const TextBuffer&, Pos, const std::string& q, AiMode) const;
381	  static void buildContext(const TextBuffer&, Pos, int max_lines,
382	                           std::string& prefix, std::string& suffix);
383	  void workerLoop();
384	  std::atomic<uint64_t> gen_{0};

386	  std::atomic<int64_t> last_activity_ms_{0};
387	  Mailbox<AiRequest> in_;  Mailbox<AppEvent>* out_;
388	  std::thread th_;
389	};

392	### 5.2 取消:generation 序号(双重过滤)
393	
394	- `gen_` 是 `std::atomic<uint64_t>`。任何缓冲区改动或光标移动 → `noteActivity()` → `gen_.fetch_add(1)`。

16	## 1. curses 只能出现在 ui.cpp,且必须先 `#define NCURSES_NOMACROS 1`
17	
18	```cpp
19	#define NCURSES_NOMACROS 1
20	#include <curses.h>
21	```
22	为什么:curses.h 把 `clear() / erase() / move() / refresh() / timeout() / scroll() /
23	border() / instr()` 定义成**函数式宏**,一旦进入公共头,`panel.h` 里的
24	`int scroll() const;`、`buf.erase(r)`、`panel.clear()` 就会被预处理器当宏调用,
25	报出 `src/panel.h:64:8: error: expected identifier before ',' token` 这种完全看不懂的错。
26	`TextBuffer::erase` 是 architecture.md 规定的名字,改不了,所以这条不可回避。
27	(实测反证见 `.flower/scripts/wave1-verify.sh` 第 3 步。)
28	
29	## 2. 归一化键码 + Alt 合成的分工
30	
31	`ui.cpp` 负责把 curses 的键**归一化**到 `keys.h` 的键码空间后才交给上层;
32	`app.cpp` 只比 `k == kKeyNone` / `k == kKeyResize`,永远不 include curses.h。
33	归一化规则:控制字符 0..0x1F 与 0x7F 原样 / `KEY_*`(0x101..0x1FF)原样 /
34	可打印字符 = `Char(cp) = 0x1000000+cp` / `KEY_RESIZE` → `kKeyResize` / `ERR` → `kKeyNone`。
35	为什么:ncurses 的 `KEY_DOWN`(0402=258)与 Unicode U+0102 数值重叠,直接返回
36	`wget_wch` 的码点会把 "Ă" 当方向键。
37	
38	Alt 的合成规则(`keys.h` 没有给签名,所以这段代码必须写在 `ui.cpp` 里,逐字照做):
39	
40	```cpp
41	// 收到 27 之后:nodelay 下再读一次
42	int second = readKeyNonBlocking();       // 内部同样要先归一化
43	return (second == kKeyNone) ? 27 : Alt(second);
44	```
45	为什么:Terminal.app 默认不发 Meta 位,把 Option 当 Esc 前缀发。**第二次读也必须先归一化**
46	再打 `kAltFlag`,否则 `Alt-←`(终端发 `ESC` `ESC[D`)拿到的是裸 `[`,`Alt(KEY_LEFT)`
47	永远匹配不上。`tests/test_keys.cpp::case_alt_synthesis` 里有一份等价实现钉住这条规则。
48	
49	## 3. `keys.cpp` 里的 KEY_* 数值是硬编码镜像
50	
51	`keys.cpp` 不能 include curses.h(见第 1 条),所以里面的 `kNcLeft = 260` 之类是手抄的。
52	唯一的看门人是 `tests/test_keys.cpp` 顶部那一排 `static_assert(KEY_LEFT == 260, ...)`。
53	为什么:数值一旦对不上,症状是"某个键没反应",极难定位;让它在编译期就红。
54	
55	## 4. 调用 util 的函数一律写 `util::` 前缀
56	
57	```cpp
58	util::basename(path)   // ✅
59	basename(path)         // ❌ 可能静默调到 glibc 的 ::basename
60	```

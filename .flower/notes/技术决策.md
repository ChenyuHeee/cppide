# 技术决策记录(Wave 1)

> 权威接口定义见 `.flower/artifacts/architecture.md`。本文件只记「为什么」。

| # | 决策 | 一句话理由 |
|---|---|---|
| 1 | 语言用 **C++17** | macOS 自带 Apple clang 与 Linux g++ 都原生支持,不需要装任何工具链就能编译。 |
| 2 | 渲染用 **ncurses(宽字符 API)** | 系统自带、无需下载;AI 面板要显示中文,必须走 `wget_wch`/`waddnwstr` 才不会把 UTF-8 拆成乱码。 |
| 3 | HTTP 用 **libcurl** | macOS 自带 libcurl,Linux 容器 apt 一装即有,且它自己就把 TLS/超时/取消回调全解决了。 |
| 4 | JSON **自己写极简实现**(`src/json.{h,cpp}`) | 环境里 github.com 不可达,不能下载 nlohmann/json;而我们只需要「对象/数组/字符串/数字/布尔 + 转义」这点能力。 |
| 5 | 构建用 **手写 Makefile** | 依赖只有两个系统库,CMake 带来的收益为零而多一层安装要求;Makefile 还能顺手放 `check-headers` 这种自定义验收门。 |
| 6 | 只用 **POSIX + ncurses + libcurl** API,零 macOS 独有调用 | 目标平台是 macOS 终端,但验证只能在 Linux 容器里做;不碰 CoreFoundation/Cocoa 才能保证「容器编译通过 ⇒ macOS 也能编译」。 |
| 7 | 可执行名定为 **`cppide`** | `icpc` 撞 Intel 编译器、`cpp` 是 C 预处理器,`cppide` 在 PATH 上无冲突。 |
| 8 | **不做选区**(改行级操作:`Ctrl-K/V/D` 剪切/粘贴/复制行) | 需求没要求;终端自身的鼠标选择 + Cmd-C 已覆盖复制场景,而选区会污染每个编辑原语和整套渲染逻辑。 |
| 9 | 练习模式靠 **`AiSink` 结构性拦截**,不靠散落的 `if (mode==...)` | sink 在请求创建时由唯一函数 `AiService::sinkFor(mode)` 定死并随事件带回,`Editor::acceptGhost()` 是缓冲区的唯一 AI 入口且开头就拒掉非 `GhostText`;写错逻辑的退化结果是「没有 ghost」,永远不是「代码被插入」。 |

## 附:Wave 1 期间确认的环境事实

- 容器为 Debian trixie/aarch64,`g++ 14.2.0` + `make 4.4.1`,**无 clang++** → Makefile 的 `CXX ?= c++` 在容器里解析到 g++,验收时显式传 `CXX=g++` 亦可。
- 宽字符必须链 **`-lncursesw`**:`libncurses.so.6` 里 `add_wch`/`get_wch` 等符号为空,链 `-lncurses` 会在 Wave 4 链接期才炸。
- 子进程一律 `fork`+`execvp`+`poll`,**绝不用 `popen`/`system`**:需要 pid 做超时 kill、需要 stdout/stderr 分离、需要真实退出状态、且不能经过 `/bin/sh`(路径含空格即出事)。
